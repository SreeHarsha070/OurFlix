💾 How Your Photos & Videos Are Stored

All photos and videos are stored locally on this device using IndexedDB — a browser database built into every modern browser. Nothing is uploaded to any server.


⚠️ Important: Because storage is local, the same device & browser must be used to see the same memories. Clearing browser data / site data will erase them. Incognito mode does not persist data.


✅ Safe: No one else can access your media. It never leaves the device. No accounts, no cloud, no tracking.


For publishing options — hosting this on a private server with a login is the most secure approach for sharing across devices. Ask the person who set this up for you 😊

📦 Export & Import — Share Across Devices
📤 Export Your Collection
All your photos and videos are stored only on this device. Use Export to save a .ourflix backup file, then Import it on any other device or browser to restore everything exactly.
Saves a single file with all photos & videos bundled inside
📥 Import Collection
Open a previously exported .ourflix file to restore everything — or to load what was uploaded from another device. Existing media is kept; duplicates are skipped.
